# Doctor Website

A React-based healthcare website project for clinic or doctor-focused presentation pages.

Live demo: https://doctor-website-three.vercel.app

## What This Project Shows
- Industry-specific website delivery for healthcare
- Reusable UI sections in React
- Responsive layout and media-rich content presentation

## Why This Stack / Tooling
- React supports reusable sections for service, doctor, and contact pages.
- React Router allows simple multi-page navigation.
- Swiper and React Icons help with presentation-heavy UI sections.

## Stack
- React
- React Router
- Swiper

## Current Status
This repository is best viewed as a frontend website build rather than a deep systems project.
